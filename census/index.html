Hub Weight Census: what AI models say about themselves

We read only the safetensors headers of 12,974 Hugging Face repositories (names, shapes and storage of every tensor, never the weights) and recovered each model's architecture from them. This page shows what widely used models are made of, how that has changed by year, and where their metadata is wrong.

Memory map of popular language models
Each dot is a language model from the table below (current filters apply), plotted by parameters (memory to hold) against KV cache per token (memory that grows with context). Dashed lines mark the largest model each device holds at 4-bit, weights only. Hover over a dot for its name; click it, or a row of the table, to select it.

Params: logical parameters (quantized storage unpacked). Hub: ✓ when the Hub's own count agrees within 0.1%, otherwise our count ÷ the Hub's. KV/token: bytes of KV cache per token at 16-bit.

Data and method

For every repo, the dataset gives status, popularity, the architecture recovered from the weights, the values its config.json declares, the Hub's own parameter count and the raw manifest, so the results can be recomputed. The code and the fixed recovery rules are public.
