Checkpoint benchmark

Runs the explorer's loader and recovery on popular public checkpoints. For each one it reads the file list, the configuration files and the safetensors headers by range request. No weights are downloaded. Results are kept in this browser as they finish, so you can close the tab and press Start again to continue. When it is done, press Download results and send the file back.
